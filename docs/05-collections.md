# 05. Коллекции ароматов как истории

## Принцип

- **Коллекция = история** (как короткий сериал), 4–5 свечей.
- **Свеча = момент** этой истории: номер, название, короткий текст-сцена (3–4 предложения),
  ароматическая пирамида.
- Свечи коллекции можно зажигать **по порядку** — история «проигрывается» запахами.
  Отсюда главный продукт для подарка: **«Вся история»** — набор мини-свечей всей коллекции.
- Новая история выходит **каждый сезон** (4 раза в год) + лимитки к праздникам и коллабы.
- У каждой истории свой цвет, плейлист (Яндекс Музыка / VK Музыка) и страница-лонгрид на сайте.

Формат подписи на этикетке:

```
AMBRE' · ТОТ САМЫЙ ДЕКАБРЬ · № 02
Мандарин в кармане
мандарин · гвоздика · снег
```

| Очередь | История | Когда |

| 1 | **Тот самый декабрь** | Ноябрь 2026 (к Новому году) |

финальная формула — после тестов горения.

## Как история работает в маркетинге

- **Анонс** за 2–3 недели: тизеры моментов без названий («угадай момент по описанию»).
- **Релиз** как премьера: в один день вся история, плейлист, лонгрид на сайте, ролики.
- **Каждую неделю** — один момент в центре внимания: видео, история, отзывы.
- **UGC:** покупатели снимают свой «момент» со свечой, лучшие — на сайт и в соцсети,
  победителям — свеча из следующей истории.
- **Коллабы:** кофейни (момент «Кофейня до открытия»), музыканты (плейлист), иллюстраторы (этикетки лимиток).
