# 04. Бриф на разработку сайта

## 1. О проекте

- **Бренд:** «Затишье» (рабочее название, см. `01-brand.md`).
- **Продукт:** ароматические свечи из растительного воска ручной работы, наборы, подарочные боксы,
  подписка, корпоративные подарки.
- **Позиционирование:** «ароматы узнаваемых моментов жизни», средний+ сегмент (1 390 ₽ за 200 мл).
- **Лозунг:** «Зажги паузу».

## 2. Цели сайта

1. Продавать онлайн (основная цель): каталог → корзина → оплата → доставка.
2. Принимать корпоративные заявки (форма + КП).
3. Строить бренд: истории ароматов, фото, отзывы, блог.
4. Собирать базу: подписка на рассылку / Telegram, промокоды, повторные покупки.

**KPI сайта:** конверсия в покупку ≥ 1,5–2%, средний чек ≥ 1 800 ₽,
скорость загрузки (LCP) < 2,5 с на мобильном, ≥ 70% трафика — мобильные устройства.

## 3. Целевая аудитория

Подробно — `02-market-analysis.md`. Кратко:
- Женщины 23–40, покупают себе для уюта (основная).
- Ищущие подарок перед праздниками.
- B2B: HR, event-агентства, свадебные организаторы.

## 4. Структура сайта

```
Главная
├── Каталог
│   ├── Все свечи
│   ├── Коллекции (Зима / Осень / Весна-лето / Лимитки)
│   ├── Наборы и подарочные боксы
│   ├── Мини-свечи
│   └── Аксессуары (спички, гасители, ножницы для фитиля)
├── Карточка товара
├── Подобрать аромат (квиз)
├── Подарки (по поводу: маме / девушке / коллегам / новоселье / до 2000 ₽)
├── Подписка «Свеча месяца»
├── Корпоративным клиентам
├── О нас (история бренда, как варим, состав)
├── Блог / Журнал (уход за свечой, истории ароматов)
├── Доставка и оплата
├── Отзывы
├── Контакты
├── Корзина → Оформление заказа → Спасибо за заказ
└── Юридические: Оферта, Политика конфиденциальности, Согласие на обработку ПДн, Cookies
```

## 5. Главная страница — блоки

1. **Первый экран:** большое фото свечи в вечернем интерьере, «Зажги паузу»,
   подзаголовок про ароматы моментов, кнопки «Выбрать аромат» и «Пройти квиз».
2. **Хиты / новогодняя коллекция** — 4–6 карточек.
3. **«Какой момент тебе нужен?»** — плитки-настроения: Уют, Энергия, Сон, Праздник, Свежесть.
4. **Почему мы:** растительный воск, хлопковый/деревянный фитиль, 35–40 ч горения,
   ручная работа, многоразовая банка (рефил −20%).
5. **Подарки** — подарочный бокс, открытка с личной надписью.
6. **Как мы варим** — 3–4 шага с фото/видео.
7. **Отзывы** — с фото покупателей.
8. **Корпоративным клиентам** — короткий блок + кнопка «Получить КП».
9. **Подписка на Telegram / рассылку** с промокодом −10%.
10. **Футер:** контакты, соцсети, юр. информация.

## 6. Карточка товара

- Галерея (4–6 фото + короткое видео горения).
- Название + **история аромата** (2–3 предложения).
- Ароматическая пирамида: верхние / средние / базовые ноты (визуально).
- Шкалы: «сила аромата», «тёплый ↔ свежий».
- Объём, вес, время горения, состав (воск, отдушка, фитиль), размер банки.
- Выбор объёма (мини / 200 мл / 400 мл) и опция «подарочная упаковка + открытка» (+ поле для текста).
- Цена, кнопка «В корзину», «Купить в 1 клик».
- Блок «Как ухаживать за свечой» (раскрывающийся).
- Отзывы с фото, рейтинг.
- «С этим ароматом покупают» / «Похожие ароматы».

## 7. Функции

### Обязательные (MVP, версия 1)
- Каталог с фильтрами: коллекция, настроение, семейство ароматов (цветочные, древесные,
  гурманские, свежие, пряные), объём, цена.
- Корзина, оформление заказа без обязательной регистрации.
- Оплата: банковские карты, **СБП**, (опционально) Долями/Сплит. Провайдер: ЮKassa / CloudPayments / Т-Банк.
- Доставка: СДЭК, Яндекс Доставка, Почта России, самовывоз; расчёт стоимости в корзине.
- Промокоды и скидки.
- Подарочная упаковка + текст открытки в заказе.
- Форма корпоративной заявки (количество, дата, бюджет, нужен ли логотип).
- Уведомления о заказе: e-mail клиенту, Telegram — владельцу.
- Админка: товары, остатки, заказы, статусы, промокоды.
- SEO-основа: ЧПУ, мета-теги, sitemap, микроразметка товаров, OpenGraph.
- Аналитика: Яндекс Метрика (цели: корзина, оформление, оплата), при необходимости VK Pixel.
- Юридическое: оферта, политика ПДн по 152-ФЗ, чекбокс согласия, баннер cookies,
  онлайн-касса/чеки по 54-ФЗ (через провайдера платежей).

### Версия 2 (после запуска)
- Квиз «Подбери аромат» (5–6 вопросов → 2–3 рекомендации + промокод).
- Подписка «Свеча месяца» (рекуррентные платежи).
- Личный кабинет: история заказов, бонусы, рефил.
- Конструктор подарочного бокса (выбрать 3 мини / свечу + аксессуары).
- Блог / журнал.
- Программа лояльности: бонусы за покупки и отзывы, «верни банку — получи скидку».
- Уведомления «сообщить о поступлении».

## 8. Дизайн

- **Настроение:** тёплый, тихий, «вечерний», много воздуха, крупные живые фото.
- **Палитра:** молочный `#F4EFE6` (фон), графит `#2B2724` (текст), терракота `#B8653A` (акцент/кнопки),
  олива `#7A7A52`, золото пламени `#E3A857`. Тёмная тема — по желанию.
- **Шрифты:** заголовки — Cormorant Garamond / Playfair Display; текст — Inter / Manrope (кириллица).
- **Микроанимации:** мягкое «мерцание» пламени, плавное появление блоков, без тяжёлых эффектов.
- **Mobile-first:** основная аудитория с телефона; липкая кнопка корзины, удобный фильтр.
- **Референсы для вдохновения:** сайты локальных брендов свечей (Flame Moscow, unification love,
  Home Lovers Club), Aesop, Diptyque — по подаче, не копировать.

## 9. Контент (что нужно подготовить)

- [ ] Фото: каталожные (на однотонном фоне) + лайфстайл (интерьер) + процесс варки.
- [ ] Короткие видео горения для карточек и первого экрана.
- [ ] Тексты: история бренда, описания-истории для каждого аромата, «как ухаживать», FAQ.
- [ ] Данные по каждому товару: ноты, состав, вес, время горения, размеры, цена, артикул.
- [ ] Логотип (SVG), фавикон, этикетки.
- [ ] Реквизиты ИП/самозанятого для юр. страниц.
- [ ] Условия доставки, возврата и обмена (бой при доставке, брак).

## 10. Технические варианты

| Вариант | Плюсы | Минусы | Когда выбирать |
|---|---|---|---|
| **Tilda + Tilda Store** | Запуск за 3–7 дней, без кода | Ограничения по логике, ежемесячная оплата | Нужно продавать уже к НГ |
| **InSales / Tilda + интеграции** | Готовый магазин, склад, доставки | Шаблонность | Средний вариант |
| **Свой сайт** (Next.js / Astro + headless-CMS + ЮKassa) | Полный контроль, скорость, уникальный дизайн, квиз и подписка как надо | Дольше (3–6 недель), нужна поддержка | Сайт v2, рост бренда |

**Рекомендация:** делаем **свой сайт в этом репозитории** поэтапно:
1. Сначала — быстрый статический сайт-витрина (Astro или Next.js) с каталогом,
   корзиной и оплатой через ЮKassa, деплой на Vercel/Netlify или российский хостинг.
2. Затем — админка/CMS для товаров, квиз, подписка.

> Важно: хранение персональных данных россиян — на серверах в РФ (152-ФЗ).
> Если будет своя база заказов, размещать её у российского хостинга (Selectel, Timeweb Cloud, Яндекс Облако).

## 12. Что нужно от владельца для старта разработки

1. Подтвердить название и лозунг.
2. Выбрать вариант: Tilda (быстро) или свой сайт (этот репозиторий).
3. Список товаров на старт (5–10 SKU) с ценами и фото (можно временные).
4. Выбрать платёжный сервис и службы доставки.
5. Домен.
