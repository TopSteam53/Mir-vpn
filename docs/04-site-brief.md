# 04. Бриф на разработку сайта

**Решение:** делаем **свой сайт** в этом репозитории (без Tilda и конструкторов).

## 1. О проекте

- **Бренд:** AMBRE' (см. `01-brand.md`).
- **Лозунг:** «Моменты, застывшие в янтаре».
- **Продукт:** ароматические свечи из растительного воска; каждая свеча — «момент»,
  каждая коллекция — история (см. `05-collections.md`). Наборы «Вся история» и «Пролог», подписка,
  лимитки, корпоративные подарки.
- **Фишка сервиса:** программа возврата банок «Retour» (см. `06-jar-return.md`).
- **Цены:** 1 390 ₽ за 200 мл, средний+ сегмент.

## 2. Цели сайта

1. Продавать онлайн: история → момент → корзина → оплата → доставка.
2. Рассказывать истории коллекций так, чтобы хотелось собрать всю историю.
3. Возвращать клиентов: «Retour», подписка, новые истории каждый сезон.
4. Принимать корпоративные заявки.
5. Собирать базу: Telegram, e-mail, промокоды.

**KPI сайта:** конверсия в покупку ≥ 1,5–2%, средний чек ≥ 1 800 ₽, доля повторных заказов ≥ 20%,
LCP < 2,5 с на мобильном. Ожидаем ≥ 75% мобильного трафика.

## 3. Целевая аудитория

Основная — **20–35 лет**, живут в соцсетях, любят эстетику, лимитки и коллабы;
покупают себе для настроения и в подарок. Плюс B2B (HR, ивент-агентства, кофейни).
Подробно — `02-market-analysis.md`.

## 4. Структура сайта

```
Главная
├── Истории (коллекции)
│   ├── Тот самый декабрь       ← страница-лонгрид истории
│   ├── Город не спит
│   └── … (новая каждый сезон)
├── Каталог (все моменты, наборы, мини, аксессуары)
├── Момент (карточка товара)
├── Подобрать аромат (квиз)
├── Подарки (по поводу / по бюджету)
├── Retour (возврат банок)
├── Подписка «Новая глава»
├── Корпоративным клиентам
├── О нас (как варим, состав, команда)
├── Журнал (уход за свечой, закулисье, плейлисты)
├── Доставка и оплата · Отзывы · Контакты · FAQ
├── Корзина → Оформление → Спасибо
└── Оферта · Политика конфиденциальности · Согласие на обработку ПДн · Cookies
```

## 5. Главная — блоки

1. **Первый экран:** вертикальное видео/фото горящей свечи в тёплом янтарном свете, «AMBRE' — Моменты, застывшие в янтаре»,
   кнопки «Смотреть историю» (текущая коллекция) и «Подобрать аромат».
2. **Текущая история** — горизонтальная лента моментов `№ 01 … № 05`.
3. **Все истории** — обложки коллекций, у каждой свой цвет.
4. **Как это работает:** «1 свеча = 1 момент», «5 моментов = история», «зажигай по порядку».
5. **Retour:** «Верни банку — получи до −250 ₽», счётчик возвращённых банок.
6. **Подарки:** набор «Вся история», подарочная упаковка, открытка с твоим текстом.
7. **Почему AMBRE':** растительный воск, хлопковый/деревянный фитиль, 35–40 ч горения, ручная работа.
8. **Отзывы и моменты покупателей** (UGC с фото).
9. **Корпоративным клиентам** — кнопка «Получить КП».
10. **Telegram / рассылка** с промокодом −10% на первый заказ.
11. **Футер.**

## 6. Страница истории (коллекции) — главная фишка сайта

- Лонгрид со «скроллтеллингом»: при прокрутке по очереди появляются моменты 01→05,
  у каждого — фото/видео, текст-сцена, ноты, кнопка «В корзину».
- Цвет-акцент страницы меняется под историю.
- Блок «Собери всю историю» — набор «Вся история» со скидкой.
- Плейлист истории (ссылка / встроенный виджет).
- Моменты покупателей с этой коллекцией.

## 7. Карточка товара («момент»)

- Метка `ТОТ САМЫЙ ДЕКАБРЬ · № 02`, название, текст-сцена.
- Галерея (4–6 фото + короткое видео горения).
- Ноты: верхние / средние / базовые; шкалы «сила аромата» и «тёплый ↔ свежий».
- Объём (мини / 200 / 400 мл), вес, время горения, состав, размеры банки.
- Опция «подарочная упаковка + открытка» (поле для текста).
- «В корзину», «Купить в 1 клик».
- Плашка «Retour: банку от этой свечи можно вернуть за 150 ₽».
- Другие моменты этой истории (навигация «← № 01 · № 03 →»).
- Уход за свечой (раскрывающийся блок), отзывы.

## 8. Функции

### Версия 1 (MVP)
- Каталог, страницы историй, карточки моментов; фильтры: история, настроение, семейство ароматов, объём, цена.
- Корзина и оформление **без обязательной регистрации**.
- Оплата: карты, **СБП**, (позже) Долями/Сплит — через **ЮKassa** (чеки по 54-ФЗ через неё же).
- Доставка: **СДЭК** (расчёт по API), Яндекс Доставка, Почта России, самовывоз.
- Промокоды: обычные, первая покупка, **промокоды «Retour»** (лимит 30%, срок 6 мес., одноразовые).
- **Retour:** страница, форма заявки на возврат, в админке «принято N банок» → генерация кода → письмо клиенту.
- Подарочная упаковка + текст открытки.
- Форма корпоративной заявки.
- Уведомления: e-mail клиенту; Telegram владельцу о новом заказе и заявке на возврат.
- Админка: товары, истории, остатки, заказы и статусы, промокоды, возвраты банок.
- SEO: ЧПУ, мета-теги, sitemap, микроразметка Product, OpenGraph-превью для каждого момента.
- Яндекс Метрика с целями (корзина → оформление → оплата), VK Pixel.
- Юридическое: оферта (с условиями «Retour»), политика ПДн по 152-ФЗ, чекбокс согласия, баннер cookies.

### Версия 2
- Квиз «Подбери аромат» → 2–3 момента + промокод.
- Подписка «Новая глава» (рекуррентные платежи ЮKassa).
- Личный кабинет: заказы, баланс «Retour», история возвратов, «моя коллекция моментов» (что уже собрал).
- Конструктор набора «Пролог» (3 мини на выбор).
- Журнал, UGC-галерея, «сообщить о поступлении», предзаказ новой истории.

## 9. Дизайн

- **Настроение:** парфюмерный бутик + вечерний свет: много воздуха, тёплое янтарное свечение, глубокие тени.
- **Палитра:** янтарь `#C8862E` (кнопки, акцент), мёд `#E9B65C` (свечение), смола `#2A1C12` (тёмные блоки, текст),
  сливочный `#F6F0E6` (фон); + цвет текущей истории (декабрь `#A3262A`, город `#6B4EFF`, юг `#2F9C95`, квартира `#8FA58A`).
- **Шрифты:** Playfair Display / Cormorant (логотип и крупные заголовки, капсом с разрядкой), Manrope / Inter (текст).
- **Элементы:** номера моментов `№ 01`, полупрозрачные янтарные блики и «капли смолы», тонкие линии-разделители.
- **Анимации:** лёгкое мерцание пламени, мягкое янтарное свечение при наведении, плавное появление моментов
  при прокрутке. Уважать `prefers-reduced-motion`.
- **Mobile-first:** липкая кнопка корзины, удобные фильтры, крупные тап-зоны.
- **Светлая и тёмная тема** (тёмная — «вечерняя», янтарь на смоле).

## 10. Технологии

| Слой | Выбор | Почему |
|---|---|---|
| Фронтенд | **Next.js (App Router) + TypeScript** | SEO, скорость, серверный рендеринг страниц товаров |
| Стили | **Tailwind CSS** | Быстро и единообразно |
| Админка / CMS | **Payload CMS** (встраивается в Next.js) | Товары, истории, заказы, промокоды, возвраты — в одной админке |
| База данных | **PostgreSQL** | Надёжно, поддерживается Payload |
| Оплата | **ЮKassa API** (+ вебхуки) | Карты, СБП, чеки 54-ФЗ, рекуррентные платежи для подписки |
| Доставка | **СДЭК API** (расчёт, ПВЗ на карте), позже Яндекс Доставка | Самые популярные |
| Письма | SMTP (Яндекс 360 / Unisender) | Подтверждения, промокоды |
| Уведомления | Telegram Bot API | Заказы и заявки — владельцу |
| Хостинг | **Российское облако** (Timeweb Cloud / Selectel / Яндекс Облако), Docker | 152-ФЗ: персональные данные россиян хранятся в РФ |
| Картинки | Next/Image + S3-совместимое хранилище в РФ | Быстрая загрузка фото |

> **Статус (октябрь 2026):** версия 1 сделана в этом репозитории на Next.js 16 + Tailwind CSS 4.
> Товары и истории пока лежат в коде (`src/data/`), заказы и заявки приходят в Telegram, оплата — ЮKassa.
> Payload CMS, PostgreSQL и API СДЭК подключаем во второй версии. Как запустить — в `README.md`.
