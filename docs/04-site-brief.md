# 04. Бриф на разработку сайта

**Решение:** делаем **свой сайт** в этом репозитории (без Tilda и конструкторов).

## 1. О проекте

- **Бренд:** KADR (см. `01-brand.md`).
- **Лозунг:** «Сохрани момент».
- **Продукт:** ароматические свечи из растительного воска; каждая свеча — «кадр»,
  каждая коллекция — история (см. `05-collections.md`). Наборы «Плёнка» и «Трейлер», подписка,
  лимитки, корпоративные подарки.
- **Фишка сервиса:** программа возврата банок «Перемотка» (см. `06-jar-return.md`).
- **Цены:** 1 390 ₽ за 200 мл, средний+ сегмент.

## 2. Цели сайта

1. Продавать онлайн: история → кадр → корзина → оплата → доставка.
2. Рассказывать истории коллекций так, чтобы хотелось собрать всю «плёнку».
3. Возвращать клиентов: «Перемотка», подписка, новые истории каждый сезон.
4. Принимать корпоративные заявки.
5. Собирать базу: Telegram, e-mail, промокоды.

**KPI сайта:** конверсия в покупку ≥ 1,5–2%, средний чек ≥ 1 800 ₽, доля повторных заказов ≥ 20%,
LCP < 2,5 с на мобильном. Ожидаем ≥ 75% мобильного трафика.

## 3. Целевая аудитория

Основная — **20–35 лет**, живут в соцсетях, любят эстетику, лимитки и коллабы;
покупают себе для настроения и в подарок. Плюс B2B (HR, ивент-агентства, кофейни).
Подробно — `02-market-analysis.md`.

## 4. Структура сайта

```
Главная
├── Истории (коллекции)
│   ├── Тот самый декабрь       ← страница-лонгрид истории
│   ├── Город не спит
│   └── … (новая каждый сезон)
├── Каталог (все кадры, наборы, мини, аксессуары)
├── Кадр (карточка товара)
├── Подобрать аромат (квиз)
├── Подарки (по поводу / по бюджету)
├── Перемотка (возврат банок)
├── Подписка «Новый кадр»
├── Корпоративным клиентам
├── О нас (как варим, состав, команда)
├── Журнал (уход за свечой, закулисье, плейлисты)
├── Доставка и оплата · Отзывы · Контакты · FAQ
├── Корзина → Оформление → Спасибо
└── Оферта · Политика конфиденциальности · Согласие на обработку ПДн · Cookies
```

## 5. Главная — блоки

1. **Первый экран:** вертикальное видео/фото горящей свечи в тёмном кадре, «KADR — Сохрани момент»,
   кнопки «Смотреть историю» (текущая коллекция) и «Подобрать аромат».
2. **Текущая история** — лента-плёнка с кадрами `01/05 … 05/05`, горизонтальный скролл.
3. **Все истории** — обложки коллекций (как постеры фильмов).
4. **Как это работает:** «1 свеча = 1 кадр», «5 кадров = история», «зажигай по порядку».
5. **Перемотка:** «Верни банку — получи до −250 ₽», счётчик возвращённых банок.
6. **Подарки:** набор «Плёнка», подарочная упаковка, открытка с твоим текстом.
7. **Почему KADR:** растительный воск, хлопковый/деревянный фитиль, 35–40 ч горения, ручная работа.
8. **Отзывы и кадры покупателей** (UGC с фото).
9. **Корпоративным клиентам** — кнопка «Получить КП».
10. **Telegram / рассылка** с промокодом −10% на первый заказ.
11. **Футер.**

## 6. Страница истории (коллекции) — главная фишка сайта

- Лонгрид со «скроллтеллингом»: при прокрутке по очереди появляются кадры 01→05,
  у каждого — фото/видео, текст-сцена, ноты, кнопка «В корзину».
- Цвет-акцент страницы меняется под историю.
- Блок «Собери всю плёнку» — набор со скидкой.
- Плейлист истории (ссылка / встроенный виджет).
- Кадры покупателей с этой коллекцией.

## 7. Карточка товара («кадр»)

- Метка `ТОТ САМЫЙ ДЕКАБРЬ · 02/05`, название, текст-сцена.
- Галерея (4–6 фото + короткое видео горения).
- Ноты: верхние / средние / базовые; шкалы «сила аромата» и «тёплый ↔ свежий».
- Объём (мини / 200 / 400 мл), вес, время горения, состав, размеры банки.
- Опция «подарочная упаковка + открытка» (поле для текста).
- «В корзину», «Купить в 1 клик».
- Плашка «Перемотка: банку от этой свечи можно вернуть за 150 ₽».
- Другие кадры этой истории (навигация «← 01/05 · 03/05 →»).
- Уход за свечой (раскрывающийся блок), отзывы.

## 8. Функции

### Версия 1 (MVP)
- Каталог, страницы историй, карточки кадров; фильтры: история, настроение, семейство ароматов, объём, цена.
- Корзина и оформление **без обязательной регистрации**.
- Оплата: карты, **СБП**, (позже) Долями/Сплит — через **ЮKassa** (чеки по 54-ФЗ через неё же).
- Доставка: **СДЭК** (расчёт по API), Яндекс Доставка, Почта России, самовывоз.
- Промокоды: обычные, первая покупка, **промокоды «Перемотки»** (лимит 30%, срок 6 мес., одноразовые).
- **Перемотка:** страница, форма заявки на возврат, в админке «принято N банок» → генерация кода → письмо клиенту.
- Подарочная упаковка + текст открытки.
- Форма корпоративной заявки.
- Уведомления: e-mail клиенту; Telegram владельцу о новом заказе и заявке на возврат.
- Админка: товары, истории, остатки, заказы и статусы, промокоды, возвраты банок.
- SEO: ЧПУ, мета-теги, sitemap, микроразметка Product, OpenGraph-превью для каждого кадра.
- Яндекс Метрика с целями (корзина → оформление → оплата), VK Pixel.
- Юридическое: оферта (с условиями «Перемотки»), политика ПДн по 152-ФЗ, чекбокс согласия, баннер cookies.

### Версия 2
- Квиз «Подбери аромат» → 2–3 кадра + промокод.
- Подписка «Новый кадр» (рекуррентные платежи ЮKassa).
- Личный кабинет: заказы, баланс «Перемотки», история возвратов, «моя коллекция кадров» (что уже собрал).
- Конструктор набора «Трейлер» (3 мини на выбор).
- Журнал, UGC-галерея, «сообщить о поступлении», предзаказ новой истории.

## 9. Дизайн

- **Настроение:** кино и плёнка — тёмный кадр с тёплым светом, контраст, крупные фото, зерно.
- **Палитра:** графит `#1C1A19`, кремовый `#F3EDE4`, оранжевый плёнки `#E8622C` (кнопки),
  янтарь `#F2A541`; + цвет текущей истории (декабрь `#A3262A`, город `#6B4EFF`, юг `#2F9C95`, квартира `#8FA58A`).
- **Шрифты:** Unbounded (заголовки), Manrope/Inter (текст), JetBrains Mono (номера кадров, ноты, цены).
- **Элементы:** перфорация плёнки как разделитель, номера кадров, рамки-полароиды.
- **Анимации:** лёгкое мерцание пламени, «перемотка» плёнки при горизонтальном скролле,
  плавное появление кадров. Уважать `prefers-reduced-motion`.
- **Mobile-first:** липкая кнопка корзины, удобные фильтры, крупные тап-зоны.
- **Светлая и тёмная тема.**

## 10. Технологии

| Слой | Выбор | Почему |
|---|---|---|
| Фронтенд | **Next.js (App Router) + TypeScript** | SEO, скорость, серверный рендеринг страниц товаров |
| Стили | **Tailwind CSS** | Быстро и единообразно |
| Админка / CMS | **Payload CMS** (встраивается в Next.js) | Товары, истории, заказы, промокоды, возвраты — в одной админке |
| База данных | **PostgreSQL** | Надёжно, поддерживается Payload |
| Оплата | **ЮKassa API** (+ вебхуки) | Карты, СБП, чеки 54-ФЗ, рекуррентные платежи для подписки |
| Доставка | **СДЭК API** (расчёт, ПВЗ на карте), позже Яндекс Доставка | Самые популярные |
| Письма | SMTP (Яндекс 360 / Unisender) | Подтверждения, промокоды |
| Уведомления | Telegram Bot API | Заказы и заявки — владельцу |
| Хостинг | **Российское облако** (Timeweb Cloud / Selectel / Яндекс Облако), Docker | 152-ФЗ: персональные данные россиян хранятся в РФ |
| Картинки | Next/Image + S3-совместимое хранилище в РФ | Быстрая загрузка фото |

## 12. Сроки (ориентир)

| Этап | Срок |
|---|---|
| Дизайн-концепция: главная, история, карточка | 3–5 дней |
| Каталог, истории, карточки, корзина (на тестовых данных) | 1–1,5 недели |
| Payload-админка, оплата ЮKassa, СДЭК, уведомления | 1 неделя |
| Перемотка, промокоды, юр. страницы, SEO, аналитика, тесты | 4–5 дней |
| **Запуск v1** | **~3–4 недели** |
| Квиз, подписка, личный кабинет (v2) | +3–4 недели |

> Чтобы успеть к Новому году: если v1 не готова к середине ноября, первые заказы
> принимать через Telegram и маркетплейс, а сайт открыть сразу после готовности.
