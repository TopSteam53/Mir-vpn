# 03. План запуска

> Сейчас октябрь 2026 — до главного сезона (ноябрь–декабрь) ~6–8 недель.
> Стратегия: **быстрый старт к Новому году** небольшой коллекцией + предзаказ
> корпоративных подарков, а полноценный сайт и широкая линейка — к весне.

## Этап 0. Решения (неделя 1)

- [ ] Финально выбрать название (см. `01-brand.md`), проверить ФИПС, домен, ники в соцсетях.
- [ ] Подать заявку на товарный знак (класс 4, при желании 3 и 35).
- [ ] Оформить **самозанятость** (если варим сами и продаём своё, до 2,4 млн ₽/год)
      или **ИП на УСН 6%** (если нужны маркетплейсы с большим оборотом, наёмные помощники, B2B-счета).
- [ ] Открыть расчётный счёт, подключить эквайринг (ЮKassa / CloudPayments / Т-Банк) + СБП.
- [ ] Уточнить требования к документам для маркетплейсов (часто просят отказное письмо /
      декларацию) и актуальность обязательной маркировки для свечей.

## Этап 1. Продукт (недели 1–3)

- [ ] Закупить пробные партии: воск (соевый или кокос-соя), 10–15 отдушек, фитили 2–3 размеров, банки.
- [ ] **Тест-горения** каждой рецептуры: туннелирование, копоть, сила аромата «холодного» и «горячего»
      броска, время горения. Записывать в таблицу (рецепт → результат).
- [ ] Выбрать **5–6 ароматов** для новогоднего старта (Бабушкин буфет, Мандарины и куранты,
      Баня после снега, Чай у камина, Сосновый бор, Чистая простыня).
- [ ] Упаковка: этикетка, коробка, гофро-вставки для доставки, открытка с историей аромата.
- [ ] Предупреждение по безопасности на этикетке (не оставлять без присмотра, обрезать фитиль, первое горение 2–3 ч).
- [ ] Соевым свечам нужно **«созревание» 7–14 дней** — учитывать в сроках производства!

## Этап 2. Мини-запуск (недели 3–6) — успеть к сезону

Каналы по порядку важности для старта:

1. **Telegram-канал + VK-группа** — витрина, процесс варки, истории ароматов, предзаказ.
2. **Простой лендинг / мини-магазин** (Tilda или наш сайт v1 — см. `04-site-brief.md`):
   каталог, корзина, оплата, доставка СДЭК / Яндекс Доставка / Почта.
3. **Маркетплейс** — Ozon или Wildberries с 3–5 SKU (ставить цену с учётом комиссии,
   делать фото и инфографику уровня бренда, а не масс-маркета).
4. **Корпоративные подарки** — с первой недели: список 50–100 компаний/агентств,
   коммерческое предложение PDF, образцы. Дедлайн приёма НГ-заказов — ~1 декабря.
5. **Офлайн** — новогодние ярмарки и маркеты (Москва/СПб: дизайн-маркеты), консигнация
   в концепт-сторах, цветочных и кофейнях.

## Этап 3. Продвижение

| Инструмент | Что делать | Бюджет на старт |
|---|---|---|
| Контент | 3–4 поста/нед.: процесс, «история аромата», распаковка, Reels/клипы VK | 0 ₽ (своими силами) |
| Блогеры | Микроблогеры 5–50 тыс. (интерьер, уход, книги): бартер + оплата | 20–60 тыс. ₽ |
| Посевы в Telegram | Каналы об уюте, интерьере, подарках | 15–40 тыс. ₽ |
| Таргет VK / Яндекс Директ | Запросы «подарок девушке», «ароматическая свеча купить» | 20–50 тыс. ₽ |
| Маркетплейс | Внутренняя реклама, первые отзывы (через раздачу образцов не нарушая правила площадки) | 15–30 тыс. ₽ |
| Удержание | Открытка с промокодом −10% на 2-ю покупку, рефил банки, подписка | — |

## Этап 4. Рост (январь–июнь 2027)

- [ ] Полноценный сайт v2: квиз «подбери аромат», подписка, личный кабинет, блог.
- [ ] Весенне-летняя коллекция (Дача в июле, После грозы, Утро в Крыму) + подарки к 8 Марта.
- [ ] Свадебные комплименты, коллаборации (кофейни, книжные магазины, художники).
- [ ] Мастер-классы по варке свечей (доп. доход + контент).
- [ ] Расширение линейки: диффузоры, саше, спреи — те же ароматы.

## Цели (KPI) на первые 3 месяца

- 300–500 проданных свечей (розница + B2B).
- 1–3 корпоративных заказа по 30–100 шт.
- 1 000+ подписчиков в Telegram/VK.
- Средний чек ≥ 1 800 ₽, доля повторных покупок ≥ 15%.
- Рейтинг на маркетплейсе ≥ 4,8.

## Что может пойти не так и что делать

| Риск | Что делаем |
|---|---|
| Не успеваем к НГ | Продаём предзаказом с датой отправки, делаем подарочные сертификаты |
| Свечи коптят / слабый аромат | Не выпускать рецептуру без 3 тестов горения |
| Бой при доставке | Гофровставки, тест «падение коробки с 1 м» |
| Летний спад | Летние ароматы, свадьбы, B2B, маркетплейсы |
| Копируют дизайн | Товарный знак, развитие бренда и сообщества |
