# AMBRE' — ароматические свечи

> «Моменты, застывшие в янтаре»

Каждая свеча — сохранённый момент, каждая коллекция — история.
Свечи из растительного воска, возврат банок со скидкой (Retour) и свой интернет-магазин.

## Что есть на сайте (версия 1)

- Главная, страницы историй (коллекций) с моментами по порядку, каталог с фильтрами, карточки товаров.
- Корзина и оформление заказа: доставка, подарочная упаковка с открыткой, промокоды.
- Оплата через ЮKassa (карта, СБП), уведомление об оплате по вебхуку.
- Программа Retour: страница, заявка на возврат банок, подписанные промокоды.
- Подарочные сертификаты (`/gift`) и набор пробников ароматов с кодом скидки на первую свечу.
- Конструктор своей свечи (`/builder`), выбор хлопкового или деревянного фитиля.
- Лист ожидания на будущие истории.
- Заявки на корпоративные подарки.
- Уведомления о заказах и заявках владельцу в Telegram.
- Светлая и тёмная тема, мобильная версия, SEO (sitemap, robots, микроразметка), Яндекс Метрика.
- Черновики оферты и политики конфиденциальности.

Пока у товаров нет фотографий, вместо снимков стоят иллюстрации свечей (`src/components/CandleArt.tsx`).

## Запуск

Нужен Node.js 22.18 или новее.

```bash
npm install
cp .env.example .env.local   # заполнить ключи, см. ниже
npm run dev                  # http://localhost:3000
```

Проверки: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

## Настройки (`.env.local`)

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта, когда появится домен |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | Онлайн-оплата. Без них заказ принимается, а оплату вы согласуете с клиентом сами |
| `YOOKASSA_SEND_RECEIPT`, `YOOKASSA_VAT_CODE` | Чеки по 54-ФЗ через ЮKassa (включить, если подключена касса) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Куда присылать заказы и заявки. Без них они пишутся только в лог сервера |
| `RETOUR_SECRET` | Секрет для промокодов Retour |
| `NEXT_PUBLIC_YM_ID` | Номер счётчика Яндекс Метрики |

В личном кабинете ЮKassa укажите адрес для уведомлений: `https://<домен>/api/yookassa/webhook`
(события `payment.succeeded` и `payment.canceled`).

## Коды: Retour, сертификаты, пробники

Все три вида — подписанные коды на фиксированную сумму (секрет `RETOUR_SECRET`, сумму в коде нельзя подделать):

```bash
npm run code -- retour 450   # скидка за возвращённые банки, 6 мес.  → RT-450-…
npm run code -- gift 3000    # подарочный сертификат, 12 мес.          → GC-3000-…
npm run code -- sample 390   # карточка в набор пробников, 6 мес.     → PB-390-…
```

- **Retour и пробники** — скидка не больше 30% от суммы товаров.
- **Сертификат** оплачивает товары (не доставку и не другие сертификаты). Если заказ меньше номинала, в уведомлении
  о заказе будет готовая команда для кода на остаток.
- **Продажа сертификатов:** с подключённой ЮKassa коды приходят в Telegram сами после оплаты; без неё в уведомлении о
  заказе будет команда для выпуска. Код нужно отправить получателю письмом в дату, указанную в заказе.

Одноразовость пока не проверяется автоматически: коды приходят в уведомлениях о заказах, сверяйте их со списком
выданных. Учёт в базе данных — в версии 2. Как оформлять продажу сертификатов в чеках (аванс по 54-ФЗ), уточните
у бухгалтера.

## Размещение

Хостинг лучше брать в России (152-ФЗ: персональные данные покупателей должны храниться в РФ).
Сборка в Docker:

```bash
docker build --build-arg NEXT_PUBLIC_SITE_URL=https://ambre.ru -t ambre .
docker run -p 3000:3000 --env-file .env.local ambre
```
